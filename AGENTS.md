# Repository Contribution Instructions

## Git workflow

- Never commit or push directly to the default branch.
- Create a descriptive topic branch for every change, including documentation and profile-only edits.
- Push the topic branch and open a pull request against the default branch.
- Do not merge a pull request without the user's explicit permission in the current conversation.
- Do not rewrite published history to manufacture a pull request after a direct push. Document the incident and use the correct workflow for the corrective change.

## Change discipline

- Stage only files intentionally changed for the task; preserve unrelated and untracked user files.
- Treat GitHub profile metadata, repository metadata, and pin changes as public remote mutations requiring explicit user authorization.
- For profile content changes, validate Markdown links, SVG syntax, and the rendered banner before requesting review.
- Report the branch, commit, pull request, verification performed, and anything still awaiting manual action.
